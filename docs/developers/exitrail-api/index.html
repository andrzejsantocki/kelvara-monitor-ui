ExitRail API

The planned stable contract for preparing, authorizing, inspecting, executing, and revoking exact exits.

Lifecycle

  1. Prepare an exact position exit.
  2. Authorize wallet-signed variants.
  3. Inspect readiness and nonce state.
  4. Bind incident evidence to policy.
  5. Execute once, then reconcile.
  6. Revoke unused authorization.
Planned public contract.

Current production routes retain legacy evacuation and protection names.
