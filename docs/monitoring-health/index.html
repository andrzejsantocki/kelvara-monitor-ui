Trust

Monitoring health

Kelvara reports whether it can still observe—not only what it last observed.

Health states

StateMeaning
HealthyCurrent evidence exists within freshness policy.
StaleEvidence is too old for a current-safe conclusion.
UnavailableThe observation path failed or returned unusable evidence.
Not monitoredNo active observation capability is configured.

Fail closed

No silent green.

Missing, malformed, stale, unavailable, or mismatched evidence is never converted into safe.
