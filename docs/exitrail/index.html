Kelvara ExitRail

Sign once. Keep your exact exit ready.

Durable authorization

An ExitRail authorization is three wallet-signed priority-fee variants of the same exit. Each fixes destination, accounts, instructions, amounts, signer set, and fee policy inside wallet-signed transaction bytes. Any mutation invalidates the signature. Durable nonces keep the exact authorization usable beyond a recent-blockhash window.

Mainnet enrollmentDurable noncesAutomatic Mainnet execution

Owner control

Kelvara may submit only an exact transaction already authorized by the owner and only when applicable policy and evidence checks permit it. Unused authorization can be invalidated by advancing or reclaiming nonce accounts.

Technical detail: transaction variants

An integration may prepare bounded priority-fee variants. Each remains a separately signed exact transaction, not an open mandate.
